# FitnessHealth – Gym Management System

## About the Project
FitnessHealth is a web-based Gym Management System developed using PHP and MySQL. It helps manage gym members, membership plans, payments, workout schedules and feedback.

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- Bootstrap
- XAMPP

## Features

### User Module
- User Registration
- User Login and Logout
- User Dashboard
- Membership Plans
- Membership Purchase
- Payment Management
- Workout Schedule
- Feedback Submission
- User Profile

### Admin Module
- Admin Login
- Admin Dashboard
- Manage Members
- Manage Membership Plans
- Manage Payments
- Manage Feedback

## Database
Database Name: `fitnesshealth_db`

## Installation and Setup

1. Install XAMPP.
2. Clone or download this repository.
3. Copy the project folder into `C:\xampp\htdocs`.
4. Start Apache and MySQL from XAMPP.
5. Open phpMyAdmin.
6. Create a database named `fitnesshealth_db`.
7. Import the project database SQL file.
8. Configure the database connection in `config.php`.
9. Open the project in your browser:

   `http://localhost/gym/home.html`
